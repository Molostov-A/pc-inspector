# PC Inspector

Локальное приложение для Windows, которое показывает, чем заняты диски, и помогает безопасно навести порядок.
Анализировать данные можно самому в браузере или в командной строке, а можно поручить это ИИ-ассистенту через MCP.

Приложение работает только на вашем компьютере: сервер слушает `127.0.0.1`, данные никуда не отправляются.

## Возможности

- **Карта диска.** Treemap и таблицы папок и файлов по размеру, как в WinDirStat.
- **Мусор.** Кэши браузеров и приложений, временные файлы, `node_modules`, `.venv`, артефакты сборки, дампы.
- **Дубликаты.** Сравнение файлов по размеру, частичному и полному хэшу BLAKE2b.
- **Забытое.** Папки и файлы, которые давно не менялись, и программы, которые давно не запускались.
- **Порядок.** Пустые папки, сортировка «Загрузок», установщики уже установленных программ, разрозненные проекты, крупные видео и образы.
- **История.** Какие папки выросли или уменьшились между сканами.
- **Планы уборки.** Просмотр, подтверждение и выполнение с возможностью отката.
- **Доступ для ИИ.** MCP-сервер со сводкой, анализаторами и SQL только для чтения.

## Безопасность

- Приложение не удаляет файлы безвозвратно: объекты уходят в карантин, в Корзину или перемещаются.
- ИИ может только анализировать и предлагать планы. Выполняет их человек.
- Системные папки, корни дисков и основные папки профиля целиком защищены от действий.
- Перед действием приложение проверяет, что объект не изменился после анализа.
- В Корзину не отправляется то, что Windows могла бы удалить мимо неё, например объект больше её квоты.

Карантин и Корзина не освобождают место сразу. Место появится после очистки карантина и Корзины.

## Требования

- Windows 10 или новее, диски NTFS
- Python 3.11 или новее
- Права администратора не обязательны. Без них недоступны Prefetch и часть системных папок

## Установка

```powershell
git clone https://github.com/Molostov-A/pc-inspector.git
cd pc-inspector
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

## Быстрый старт

1. Дважды щёлкните `start-web.bat`. Откроется [http://127.0.0.1:8765](http://127.0.0.1:8765).
2. Нажмите **Сканировать**. Пустой список означает все локальные диски NTFS.
3. Изучите **Главную**, **Обзор** и **Мусор**.
4. Отметьте лишнее и нажмите **Добавить в план**.
5. В разделе **Планы** проверьте пункты, выберите действия и подтвердите выполнение.
6. Если нужно что-то вернуть, откройте **Историю** и нажмите **Откатить**.

Запуск вручную:

```powershell
.\.venv\Scripts\python.exe -m pcinspector serve --open
```

## Разделы интерфейса

| Раздел | Назначение |
|---|---|
| Главная | Диски, итоги мусора, крупные папки |
| Обзор | Карта размеров и таблица содержимого папок |
| Мусор | Находки по группам с оценкой безопасности |
| Дубликаты | Группы одинаковых файлов и выбор копии, которую оставить |
| Забытое | Давние папки и файлы, неиспользуемые программы, возможные остатки |
| Порядок | Сортировка загрузок, пустые папки, рост папок и другие отчёты |
| Анализаторы | Любой анализатор с настройкой параметров |
| Планы | Просмотр и выполнение планов уборки |
| История | Журнал действий, откат, карантин |
| Настройки | Корни сканирования, исключения, порог давности, путь карантина |

## Действия в плане

| Действие | Что происходит | Откат |
|---|---|---|
| В карантин (по умолчанию) | Перенос в `<диск>:\.pci-quarantine` на том же диске | Из «Истории» |
| Очистить содержимое | Папка остаётся, в карантин уходят объекты старше суток. Занятые файлы пропускаются | Из «Истории» |
| Переместить | Перенос в указанный путь на том же диске | Из «Истории» |
| В Корзину | Отправка в Корзину Windows | Вручную из Корзины |
| Пустую папку в Корзину | Для папок без содержимого | Вручную из Корзины |

Очистка карантина старше заданного срока переносит элементы в Корзину и требует подтверждения.

## Командная строка

Команды ниже выполняются из активированного окружения (`.\.venv\Scripts\Activate.ps1`).

```powershell
python -m pcinspector scan C:\ B:\          # сканировать диски или папки
python -m pcinspector hash --min-size 1M    # посчитать хэши для поиска дубликатов
python -m pcinspector apps                  # собрать сведения о программах
python -m pcinspector analyzers             # список анализаторов и параметров
python -m pcinspector junk --json           # запустить анализатор, вывод в JSON
python -m pcinspector brief                 # Markdown-сводка для ИИ
python -m pcinspector sql "SELECT path, size FROM files_v ORDER BY size DESC LIMIT 10"
python -m pcinspector plan --help           # create, list, show, add, execute
python -m pcinspector quarantine --help     # list, restore, purge
```

Папка внутри уже просканированного корня обновляет этот корень. Для отдельного индекса укажите `--db PATH`.

### Анализаторы

| Группа | Идентификаторы |
|---|---|
| Обзор | `roots`, `tree`, `top_files`, `types` |
| Уборка | `junk`, `duplicates`, `empty_dirs` |
| Давнее | `stale_files`, `forgotten_dirs` |

| Порядок | `downloads_sort`, `scattered_projects`, `big_media` |
| История | `growth` |

## Подключение ИИ через MCP

Сервер запускается командой `python -m pcinspector mcp` и работает через stdio. Инструменты MCP не изменяют файлы:
ИИ получает сводку, отчёты и SQL только для чтения, запускает скан и создаёт черновики планов.

**Claude Code**, из папки проекта:

```powershell
claude mcp add --transport stdio pc-inspector -- "<папка проекта>\.venv\Scripts\python.exe" -m pcinspector mcp
```

**Claude Desktop**, файл `%APPDATA%\Claude\claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "pc-inspector": {
      "command": "<папка проекта>\\.venv\\Scripts\\python.exe",
      "args": ["-m", "pcinspector", "mcp"]
    }
  }
}
```

Пример запроса: «Используй PC Inspector, объясни, чем занят диск C, и предложи план уборки».
План от ИИ появится в разделе **Планы** с меткой **ИИ**. Выполнить его можете только вы.

## Где хранятся данные

| Путь | Содержимое |
|---|---|
| `data/index.db` | Результаты сканирования и история размеров |
| `data/index.state.db` | Планы, журнал действий, настройки, хэши, сведения о программах |
| `data/logs/pci.log` | Журнал приложения |
| `<диск>:\.pci-quarantine` | Карантин. Путь можно изменить в настройках |

Переменные окружения: `PCI_DB` задаёт путь к индексу, `PCI_QUARANTINE` — папку карантина.

## Известные ограничения

- Windows часто не обновляет дату последнего доступа, поэтому «давно не использовался» — приблизительная оценка.
- Сумма размеров может отличаться от свойств диска из-за недоступных папок и жёстких ссылок.
- Первый скан большого диска может занять несколько минут и зависит от скорости чтения метаданных.
- Параметры расписания сохраняются, но автоматический запуск пока не реализован.
- Пакеты Microsoft Store в списке программ не учитываются.
