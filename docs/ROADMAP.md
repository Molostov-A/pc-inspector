# ROADMAP — этапы разработки PC Inspector

Правила: этапы выполняются по порядку; внутри этапа — сверху вниз. Задача закрывается `[x]` только
с тестами (см. Definition of Done в AGENTS.md). В скобках — ID требований из SPEC.md.
Каждый этап заканчивается **проверкой приёмки** — её выполняет человек или агент вручную.
