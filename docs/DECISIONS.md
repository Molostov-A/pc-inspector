# Журнал решений (ADR, кратко)

Формат: дата — решение. Контекст. Последствия.

## 2026-11-07 — Стек: Python + SQLite + FastAPI + ванильный JS/ECharts + MCP
Контекст: пользователь пишет на Python; приложение должно легко развиваться разными LLM.
Решение: один процесс на Python, индекс в SQLite, веб-UI без сборки (никакого npm), MCP через официальный SDK.
Последствия: нет шага сборки фронтенда; UI проще, чем на React, но любой агент правит его без инфраструктуры.

## 2026-11-07 — Плагинные анализаторы с единым форматом Report/Finding
Контекст: анализов будет много, и добавлять их должны разные агенты.
Решение: `@register` + метаданные `params`; CLI, API, MCP и UI строятся из реестра автоматически.
Последствия: новый анализатор — один файл; нестандартный UI нужен только для специальных экранов.

## 2026-11-07 — ИИ только анализирует и предлагает, выполняет человек
Контекст: ошибка ИИ при удалении файлов необратима и опасна.
Решение: в MCP нет инструментов, меняющих ФС; выполнение — только через UI/CLI с подтверждением; нет безвозвратного удаления.
